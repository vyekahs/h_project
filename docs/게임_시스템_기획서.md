## 1. 개요

### 1.1 문서 목적

본 기획서는 현재 운영 중인 웹서비스 시스템에 **포인트 상점**, **랭킹 시스템**, **칭호 시스템**을 추가하기 위한 상세 기획을 담고 있습니다.

### 1.2 시스템 목표

| 목표 | 설명 |
|------|------|
| 🎯 유저 참여도 향상 | 경쟁 요소와 보상 시스템을 통한 지속적인 동기부여 |
| 👥 커뮤니티 활성화 | 랭킹 경쟁과 칭호 시스템을 통한 건전한 경쟁 문화 조성 |

## 2. 게임별 랭킹 시스템

### 2.1 핵심 개념

각 게임마다 **독립적인 실시간 순위 보드**를 운영하여, 유저들이 게임별로 자신의 순위를 확인하고 경쟁할 수 있도록 합니다.

### 2.2 랭킹 산정 기준

| 랭킹 유형 | 적용 게임 예시 | 기준 |
|-----------|----------------|------|
| ⏱️ 최단 시간 클리어 | 스도쿠, 퍼즐 게임 | 완료 소요 시간 (낮을수록 상위) |
| 🏆 최고 점수 | 아케이드, 슈팅 게임 | 획득 점수 (높을수록 상위) |
| 📊 복합 기준 | 전략 게임 | 점수 × 시간 가중치 |

### 2.3 랭킹 보드 구조

```
┌─────────────────────────────────────────────────┐
│  🎯 스도쿠 랭킹 (이지 모드)                      │
├──────┬────────────────┬───────────┬─────────────┤
│ 순위 │     닉네임      │   기록    │    날짜     │
├──────┼────────────────┼───────────┼─────────────┤
│  1   │ [스도쿠 깎는] 홍길동 │  02:34  │ 2026.01.15 │
│  2   │ 김철수          │  02:58   │ 2026.01.20 │
│  3   │ 이영희          │  03:12   │ 2026.01.18 │
└──────┴────────────────┴───────────┴─────────────┘
```

### 2.4 랭킹 갱신 정책

- **실시간 갱신**: 게임 완료 즉시 랭킹 반영
- **개인 최고 기록만 등록**: 동일 유저의 여러 기록 중 최고 기록만 표시
- **난이도별 분리**: 같은 게임이라도 난이도별로 별도 랭킹 운영

### 2.5 랭킹 표시 범위

| 구분 | 표시 범위 | 비고 |
|------|-----------|------|
| 메인 보드 | TOP 100 | 전체 공개 |
| 내 순위 | 본인 ±10위 | 100위권 밖일 경우 |
| 히스토리 | 최근 30일 | 기록 변동 추이 |

## 3. 칭호 시스템

### 3.1 핵심 개념

칭호는 **닉네임 앞에 표시되는 특별한 수식어**로, 동아리 내에서 **단 한 명만 보유**할 수 있는 희소성 있는 보상입니다.

### 3.2 칭호 표시 형식

```
[칭호명] 닉네임

예시:
[스도쿠 깎는] 홍길동
[퍼즐의 신] 김철수
[불굴의 도전자] 이영희
```

### 3.3 칭호 종류 및 획득 조건

| 칭호명 | 획득 조건 | 대상 게임 |
|--------|-----------|-----------|
| 🧩 스도쿠 깎는 | 스도쿠(하드) 최단 클리어 1위 | 스도쿠 |
| ⚡ 번개손 | 스도쿠(이지) 최단 클리어 1위 | 스도쿠 |
| 🧠 퍼즐의 신 | 퍼즐게임 종합 점수 1위 | 퍼즐 |
| 🔥 불굴의 도전자 | 최다 게임 클리어 1위 | 전체 |
| 💎 포인트 부자 | 누적 포인트 획득 1위 | 전체 |
| 🎁 나눔의 손길 | 선물 횟수 1위 | 커뮤니티 |

### 3.4 칭호 이동 로직

```
┌─────────────────────────────────────────────────────────┐
│                    칭호 이동 플로우                       │
└─────────────────────────────────────────────────────────┘

  [기존 1위: 유저A]                [도전자: 유저B]
        │                              │
        │    기록: 03:00               │    신기록: 02:45
        │                              │
        └──────────────┬───────────────┘
                       │
                       ▼
              ┌────────────────┐
              │ 기록 비교 판정  │
              └────────────────┘
                       │
           ┌───────────┴───────────┐
           │                       │
           ▼                       ▼
    [유저B 신기록]           [기록 미달]
           │                       │
           ▼                       ▼
  ┌─────────────────┐      변동 없음
  │ 칭호 즉시 이동   │
  │ 유저A → 유저B   │
  └─────────────────┘
           │
           ▼
  ┌─────────────────┐
  │ 알림 발송        │
  │ • 유저A: 칭호 상실│
  │ • 유저B: 칭호 획득│
  └─────────────────┘
```

### 3.5 칭호 시스템 규칙

1. **1인 1칭호 원칙**: 한 유저가 여러 칭호 조건을 충족해도 **최대 1개만 표시**
2. **우선순위 설정**: 복수 칭호 보유 시 유저가 표시할 칭호 선택 가능
3. **즉시 이동**: 기록 경신 시 **실시간으로 칭호 이동**
4. **알림 시스템**: 칭호 획득/상실 시 푸시 알림 발송

## 5. 데이터베이스 설계안

### 5.1 주요 테이블 구조

```sql
-- 유저 포인트 테이블
CREATE TABLE user_points (
    user_id         BIGINT PRIMARY KEY,
    total_points    INT DEFAULT 0,
    daily_earned    INT DEFAULT 0,
    last_earned_at  TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 랭킹 테이블
CREATE TABLE game_rankings (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    game_id         VARCHAR(50) NOT NULL,
    difficulty      ENUM('easy', 'normal', 'hard', 'expert'),
    user_id         BIGINT NOT NULL,
    score           INT,
    clear_time      INT,  -- 초 단위
    achieved_at     TIMESTAMP DEFAULT NOW(),
    UNIQUE KEY unique_ranking (game_id, difficulty, user_id)
);

-- 칭호 테이블
CREATE TABLE titles (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    title_code      VARCHAR(50) UNIQUE NOT NULL,
    title_name      VARCHAR(100) NOT NULL,
    description     TEXT,
    condition_type  VARCHAR(50),  -- 'ranking', 'achievement', 'community'
    condition_value JSON
);

-- 유저 칭호 보유 테이블
CREATE TABLE user_titles (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT NOT NULL,
    title_id        BIGINT NOT NULL,
    acquired_at     TIMESTAMP DEFAULT NOW(),
    is_displayed    BOOLEAN DEFAULT TRUE,
    UNIQUE KEY unique_user_title (title_id)  -- 칭호당 1명만 보유
);

-- 상점 아이템 테이블
CREATE TABLE shop_items (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    item_code       VARCHAR(50) UNIQUE NOT NULL,
    item_name       VARCHAR(100) NOT NULL,
    description     TEXT,
    price           INT NOT NULL,
    item_type       ENUM('game_assist', 'community', 'cosmetic'),
    use_limit       JSON,  -- {"per_game": 3, "per_day": 10}
    is_active       BOOLEAN DEFAULT TRUE
);

-- 유저 인벤토리 테이블
CREATE TABLE user_inventory (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT NOT NULL,
    item_id         BIGINT NOT NULL,
    quantity        INT DEFAULT 0,
    UNIQUE KEY unique_inventory (user_id, item_id)
);

-- 포인트 거래 로그
CREATE TABLE point_transactions (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT NOT NULL,
    amount          INT NOT NULL,  -- 양수: 획득, 음수: 사용
    transaction_type ENUM('game_clear', 'bonus', 'purchase', 'gift_sent', 'gift_received'),
    reference_id    VARCHAR(100),
    created_at      TIMESTAMP DEFAULT NOW(),
    INDEX idx_user_date (user_id, created_at)
);
```

### 5.2 인덱스 설계

```sql
-- 랭킹 조회 최적화
CREATE INDEX idx_ranking_lookup 
ON game_rankings (game_id, difficulty, clear_time ASC);

-- 일일 포인트 집계
CREATE INDEX idx_daily_points 
ON point_transactions (user_id, created_at, transaction_type);

-- 칭호 조건 확인
CREATE INDEX idx_title_condition 
ON titles (condition_type, id);
```

| 위치 | 광고 크기 | 노출 시점 | 우선순위 |

#### 6.1.2 핵심 원칙

> ⚠️ **게임 플레이 영역에는 절대 광고를 배치하지 않습니다**

- 게임 중 실수로 광고 클릭 → 사용자 이탈 + 애드센스 정책 위반 위험
- 게임 집중도 저하 → 서비스 만족도 하락

### 6.2 보상형 광고 (AdMob Rewarded Ads 연계)

사용자가 **자발적으로 광고를 시청**하고 **포인트 보상**을 받는 구조입니다. 포인트 시스템과 자연스럽게 연계됩니다.

#### 6.6.2 보상형 광고 (AdMob 연동 시)

```javascript
// 보상형 광고 초기화
function initRewardedAd() {
  googletag.cmd.push(function() {
    rewardedSlot = googletag.defineOutOfPageSlot(
      '/XXXXXX/rewarded-ad',
      googletag.enums.OutOfPageFormat.REWARDED
    ).addService(googletag.pubads());
    
    googletag.pubads().addEventListener('rewardedSlotReady', (event) => {
      event.makeRewardedVisible();  // 광고 표시
    });
    
    googletag.pubads().addEventListener('rewardedSlotClosed', (event) => {
      // 보상 지급 처리
      if (event.payload) {
        grantReward(event.payload.amount, event.payload.type);
      }
    });
  });
}

// 보상 지급
function grantReward(amount, type) {
  fetch('/api/points/reward', {
    method: 'POST',
    body: JSON.stringify({ amount: 20, source: 'rewarded_ad' })
  });
}
```
